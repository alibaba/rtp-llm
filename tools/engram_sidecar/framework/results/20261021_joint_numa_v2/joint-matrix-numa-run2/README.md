# Joint two-layer full matrix, NUMA v2 — 2026-10-21

**The real two-layer setup and cleanup completed, but the observed lookup latency
threshold did not pass.** Across M=1..64, Graph GPU-event remote-minus-local
increments exceeded 100 µs in **11/140,000 pairs**, reaching **1,490.176 µs**.
For the priority M=1 Graph case, hot/random P99 increments were **7.936/7.360 µs**
and maxima **18.176/90.912 µs**, with no GPU-event exceedance in those 20,000 pairs.
M=1 wall time nevertheless has 8 positive exceedances. Full decode remains
`NOT_MEASURED`: this is two serial real lookups without intervening model work.

This run is complete in its recorded scope: 14 cases (7 batches × eager/Graph),
2 distributions and 10,000 pairs per distribution, totaling **1,120,000 raw
records / 280,000 pairs**. All cases and all eight zero consumer-native resource
counters appear in `complete.json`. A complete run is not a latency pass.

## Timing, outputs and cache boundary

Both actual lookups run sequentially on one stream inside a single event or
Graph window and return two BF16 outputs. The measured joint delta is computed
from each paired call, never by summing per-layer P99s. The inputs of the two
layers are independent; hash/history, WKV/projection, gating, real layer-to-layer
model dependencies, attention/MoE/EP traffic, scheduling and HTTP are absent.

Each case checks both actual local/remote layer outputs against an independent
original checkpoint FP8/E8M0-to-BF16 oracle at random indices 0 and 1 before
timing, hot index 0 afterward, and random index 9,999 afterward. Graph checks
inspect actual guarded replay outputs. This verifies recorded checkpoints, not
every sampled output. Complete cleanup is ordered after Graph references and
local registered tables are released; zero native counters apply to this
consumer, not the separate Owner or all system page cache.

Hot IDs are fixed; random IDs are uniform over the full tables. **Full table size
is not the active working set**, and this run has `cache_claim=uncontrolled`.
No L2 disturbance was used. At M=1, two layers × 24 heads × 264 bytes per selected
row × 10,000 samples is at most 126,720,000 logical bytes (**120.850 MiB**) per
backend before duplicates and cache-line overfetch. Runtime L2 is 129.25 MiB;
local and remote have different backing, and eager/Graph reuse the trace. These
facts neither prove all hits nor prove cold access. Larger M enlarges the trace
working set but also does not establish cold residency or production locality.
Full-model cache pressure is absent. The [scratch-disturbed M=1/M=2 run](../joint-M1M2-disturbed-run3/README.md)
is reported separately with `scratch_disturbed_not_guaranteed_cold`.

GPU eager events include CPU dispatch gaps. Graph uses external timing-event
nodes captured inside the guarded Graph, so a long event interval is distinct
from submit-to-completion wall time, but it is still not a link-only or exclusive
kernel measurement. Wall submission and completion synchronization are retained
separately; the synchronization call is not exclusively GPU-compute waiting.
Timing instrumentation and empty controls are never subtracted.

The largest GPU case, M4 random pair 4502, has a short remote submit (30.144 µs)
and long event interval (1,505.696 µs) plus completion call (1,507.684 µs).
It cannot be explained merely as a long host submit call. In contrast, M2 random
pair 3880 has remote submit 330.081 µs and GPU interval 310.784 µs; those elapsed
intervals overlap and cannot be added or assigned to a subsystem without tracing.
M32 pair 5954 also has a slow local 186.080 µs GPU interval, so the comparison is
not a stable local background at every outlier.

The maximum Graph wall increment is M16 random pair 6347: remote wall
122,998.799 µs (submit 122,898.798, completion 100.001), versus local 49.120 µs.
The same pair's GPU intervals are only 37.888 versus 17.664 µs, delta 20.224 µs.
One remote involuntary thread switch is recorded. This supports distinguishing
the host-wall spike from the GPU interval; it does not prove the complete delay
was caused by the OS or establish a network/fabric cause.

The opposite tail is retained: M2 Graph random pair 6544 has local wall
111,358.316 µs, primarily submit 111,320.235 µs, with zero counted switches;
remote wall is 122.465 µs. Its wall delta is -111,235.851 µs while GPU delta is
-16.320 µs. M64 Graph hot pair 1409 has a local GPU interval 432.480 µs versus
remote 24.384 µs, delta -408.096 µs. These baseline anomalies are not deleted or
used to cancel positive failures. Eager M32 random pair 2827 has GPU delta
132,664.185 µs and wall delta 132,776.844 µs with one remote involuntary switch;
the eager dispatch-gap boundary prevents calling that pure GPU service time.

[anomaly_neighborhoods.json](anomaly_neighborhoods.json) retains ±2 paired samples
around every Graph GPU exceedance and selected positive/negative extremes in the
same epoch. [outlier_examples.json](outlier_examples.json) includes extremes and
calibration examples; all controls and unselected raw samples remain in the
archive. Neighborhoods show what happened nearby, not the cause of the spike.
For example, M2 pair 3880's adjacent GPU deltas are 5.024, 5.152, **296.864**,
5.344 and 4.736 µs; the large sample is isolated in that small neighborhood.
M8 pair 2113 and M32 pair 5954 are followed by slow local intervals, producing
negative deltas: nearby baseline behavior is not uniformly stable.

The seven Graph cases also retain 700 event-only and 700 empty-Graph control
samples. Event-only GPU intervals span 3.232–9.024 µs, with wall maximum
29.120 µs; empty-Graph wall maximum is 41.600 µs. Those finite controls contain
no >100 µs observation, but do not rule out an instrumentation or system tail
during the much longer workload. Event-node overhead is material at this scale
and is not a constant that can be subtracted from P99 or an anomalous sample.
The current evidence does not attribute these anomalies to fabric, OS or a
particular kernel. No tails are filtered, replaced or subtracted.
