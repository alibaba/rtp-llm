## 说明

- “真实请求 warmup 合计”是 20 条请求日志中 `cost` 的求和，和该阶段墙钟时间基本一致。
- “整体启动”还包括进程拉起、模型加载、权重准备、通信初始化和 cache 初始化等阶段，不应全部归因于 remote JIT cache。
- 单次对比会受到机器负载和 I/O 波动影响，但编译长尾从几十/上百秒降到亚秒的幅度足够明显，可以判断 remote JIT cache 已产生实际收益。
- 如需更稳定的结论，建议保持相同配置再做至少 3 次冷本地目录、热远端 snapshot 的重启，统计中位数和 P90。
