# 全样本最小二乘与线上逐样本学习对比

本报告回答：把一个采样窗口内的高、中、低压力样本**全部用于同一次拟合**，每个节点得到一组固定的 v21 基础公式参数后，高低压各有多少误差；与相同请求上的线上基础预测及 residual 综合预测相比，差异有多大。没有划分训练/留出集，也没有更改生产模型或配置。

## 数据与方法

- A 窗口：MI308 10 节点、25447 条样本；RTX 5000 9 节点、17429 条。B 窗口：各 10 节点，MI308 67805 条、RTX 5000 46468 条。两个窗口来自独立采样；各节点分别拟合，再按样本数汇总 MAE。
- 每个节点**所有压力样本共同参与**一组静态参数的最小二乘拟合。低压仅是评分子集，条件为调度输入 `running<=4 && waiting<=4`；高压评分子集为 `waiting>=33`。中间压力样本也参与拟合，不被丢弃。
- 主实验最小化 `(log1p(预测)-log1p(真值))^2`；对照实验最小化原始毫秒误差平方。用日志中的初始、中间、最终参数多起点优化。A 窗口两个首次达到评估上限的节点从已有解续算；最终 39 个节点的主实验均达到优化器终止条件，但非凸问题不能据此证明数学全局最优。
- `online base` 是请求当时更新前的基础模型预测；`online final` 是同一请求包含 residual 的综合预测。逐样本基础公式复算与日志值的最大差小于 `5.17e-10ms`。三者在**同批请求**上计算 MAE，单位均为 ms。
- 静态模型在评分前已见过这些请求的真值，因此结果是**样本内拟合能力**，并非未来预测效果；与线上轨迹的差距不是受控的优化器 A/B 实验。

## 全样本拟合结果

每格依次为静态最小二乘 / online base / online final 的 MAE，单位 ms。低压、高压只是将同一组全样本拟合后的参数分别评分。

| 窗口/硬件 | 低压样本 | 低压 MAE：静态 / base / final | 高压样本 | 高压 MAE：静态 / base / final |
| --- | ---: | ---: | ---: | ---: |
| A MI308 | 3725 | 182 / 215 / 179 | 11473 | 12935 / 9275 / 2855 |
| A RTX 5000 | 4546 | 312 / 337 / 334 | 8833 | 2435 / 3083 / 1595 |
| B MI308 | 18647 | 104 / 136 / 122 | 31195 | 13156 / 13344 / 10895 |
| B RTX 5000 | 17321 | 322 / 357 / 344 | 23232 | 1658 / 2777 / 1795 |

- **MI308 A：**高压静态比 online base 差 3660ms，比 online final 差 10080ms；两项在 10/10 节点均同方向。它能把低压拟合到 182ms，却没有用一组静态基础参数同时达到线上综合预测的高压误差。线上 final 的优势包含 residual，不能全归因于基础参数更新。
- **MI308 B：**高压静态与 online base 只差 -188ms，但比 final 差 2261ms；后一个方向在 10/10 节点一致。A 的大差距没有在 B 的基础预测对比中重现，不能把 A 结果当成 MI308 的固定属性。
- **RTX 5000：**高压静态比 online base 分别好 648ms、1119ms；B 窗口也比 final 好 137ms。A 窗口静态比 final 差 840ms，其中一个节点差距异常大，不能只看平均值推断架构整体。RTX 的线上基础参数轨迹在这两段数据上不总优于单组静态拟合。
- 真值 `<256ms` 的短延迟子集不是上述低压定义。四组短延迟样本内 MAE，静态 / final 分别约为 A MI `32/40`、A RTX `32/37`、B MI `40/41`、B RTX `31/32`ms；高压收益不能用这项近零点表现替代。

## 损失函数敏感性

两种拟合都使用窗口内全部压力样本，仅更换最小二乘残差的定义。下表是静态模型的低压 / 高压 MAE，单位 ms。

| 窗口/硬件 | log1p 平方损失 | 原始毫秒平方损失 |
| --- | ---: | ---: |
| A MI308 | 182 / 12935 | 959 / 8992 |
| A RTX 5000 | 312 / 2435 | 495 / 2121 |
| B MI308 | 104 / 13156 | 565 / 10944 |
| B RTX 5000 | 322 / 1658 | 419 / 1559 |

原始平方损失提高了四组高压的样本内准确度，但全部损害低压；MI308 的低压 MAE 增加约 5-6 倍。A MI308 即使高压降到 8992ms，也仍高于 online final 的 2855ms。B MI308 高压接近 final，但低压从 104ms 升到 565ms。这说明损失函数的压力权衡很强；不能只看高压一项认定公式已经兼顾各阶段。

## 结论边界与后续判别

1. 全样本结果说明：当前静态公式和这两种全局损失设置下，MI308 A 窗口无法同时复现低压和高压的线上综合精度；RTX 5000 的静态高压拟合则已接近线上综合精度。B MI308 的静态基础拟合接近线上基础预测，不能说 MI308 所有窗口都必须靠基础参数快速变化。
2. 这组对比**不能区分**漏了压力/工作量特征、公式形式不足、调度与执行的目标时序错位，还是 residual 的动态状态作用；也不能单独证明 Adam 学习率是根因。MI 与 RTX 的请求分布、排队状态和真实耗时范围不同，不可将差异直接归因于硬件型号。
3. 这里的秒级差异在观察样本内是实际存在的，但静态模型使用了评估样本的真值，节点还共享同一流量阶段，因此不报告独立样本的统计显著性或部署收益。若要验证新公式/特征的泛化及在线跟随，须在相同事件顺序、相同初态下重放，并再做真实压测验证。
